# cRustDesk 1.5.1-1

- **Upgrade the server and the clients together.** Our protocol fields now start at 1001, so that
  upstream's new fields do not take them. Devices older than 1.5.1-1 on rustdesk-server 1.1.16-9
  (or 1.5.1-1 devices on an older server) do not get same-user access, and a device whose key the server refuses
  does not show why.
- Text paste (the clipboard sent on request) needs 1.5.1-1 on both the viewer and the device, or web
  client 2.1.0 as the viewer.
- The OS login message (auto-login) uses the same field number as stock RustDesk 1.5.1.
- Based on upstream RustDesk 1.5.1: keyboard shortcuts for session actions (off by default),
  Windows installer hardening, auto-login types the OS password only at the logon or lock screen,
  and Linux (Wayland, X11) and macOS fixes. Our `hbb_common` fork merges upstream's matching changes.
- Works with rustdesk-server 1.1.16-9, rustdesk-api 3.9.0 and Helm chart 0.15.0.
